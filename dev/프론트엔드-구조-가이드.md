# 프론트엔드 구조 가이드

teum-frontend 의 **폴더 구조·화면 구성·디자인 시스템(Astryx)** 사용법을 정리한 문서입니다. 프론트 코드를 처음 열어 보는 팀원이 어디를 고쳐야 하는지 찾을 수 있게 하는 것이 목적입니다.

> **현재 상태 (2026-11-17 기준)**
> - teum-frontend **PR #26 (Astryx 기반 화면 개편)** 반영 기준으로 작성했습니다. 병합 전이라면 `style/astryx-interactive-redesign` 브랜치에서 확인하세요.
> - 화면은 **Astryx 컴포넌트 + `teum` 테마**로 그립니다. 메인 컬러는 **#036635(초록) + 흰색**입니다.
> - 백엔드 호출 코드(`src/lib`)는 화면 개편과 무관하게 그대로입니다.
> - 실행 방법은 [로컬 개발 환경 셋업](./로컬-개발-환경-셋업.md)을 따릅니다.

| 아이콘 | `@heroicons/react` | |
| 서체 | IBM Plex Sans KR (`@fontsource`) | |
| 인증 | Supabase JS | 이메일 로그인 + Google 소셜 로그인 |

## 2. 폴더 구조

```
teum-frontend/
├── src/
│   ├── app/                  # 화면(라우트)
│   │   ├── layout.tsx        # 전체 틀 — globals.css 를 가장 먼저 불러옴
│   │   ├── providers.tsx     # 테마 · 한국어 문구 · 내부 링크 연결
│   │   ├── globals.css       # 레이어 순서 선언 + 시간표 칸 색
│   │   ├── page.tsx          # 첫 화면 (비로그인)
│   │   ├── login/ signup/    # 로그인 · 회원가입
│   │   ├── onboarding/       # 가입 직후 프로필 · 시간표 등록
│   │   ├── (main)/           # 로그인 후 화면 (모임 · 내 시간표 · 내 정보)
│   │   └── share/[token]/    # 확정 일정 공개 페이지 (비회원 열람)
│   ├── components/           # 화면 조각
│   │   ├── layout/           # 공통 틀 (AppFrame, AuthFrame, useConfirm 등)
│   │   ├── auth/             # 구글 로그인 버튼, 프로필 입력
│   │   ├── landing/          # 첫 화면 예시 시간표
│   │   ├── timetable/        # 시간표 격자 · 편집기 · 이미지 등록
│   │   └── meeting/          # 추천 시간 · 팀원 · 메모 · 모임 폼
│   ├── lib/                  # 백엔드 호출 함수 (기능별 파일)
│   ├── types/                # API 응답 타입
│   ├── themes/teum/          # 테마 사본 (자동 생성 — 직접 수정 금지)
│   └── astryx-themes.ts      # 테마 연결 모듈 (자동 생성)
└── themes/teum/              # 테마 원본 (편집기가 관리)
```

## 3. 화면 목록

| 주소 | 화면 | 파일 |
| --- | --- | --- |
| `/` | 첫 화면 (눌러 볼 수 있는 예시 시간표) | `app/page.tsx` |
| `/login`, `/signup` | 로그인 · 회원가입 | `app/login`, `app/signup` |
| `/onboarding/profile` | 프로필 입력 | `app/onboarding/profile` |
| `/onboarding/timetable` | 시간표 등록 (이미지 / 직접 입력) | `app/onboarding/timetable` |
| `/meetings` | 내 모임 목록 | `app/(main)/meetings` |
| `/meetings/new` | 모임 생성 | `app/(main)/meetings/new` |
| `/meetings/{id}` | 모임 상세 (추천 시간 · 팀원 · 메모 · 모임 관리 탭) | `app/(main)/meetings/[meetingId]` |
| `/meetings/{id}/edit` | 모임 조건 수정 | `app/(main)/meetings/[meetingId]/edit` |
| `/me/timetable` | 내 시간표 | `app/(main)/me/timetable` |
| `/me` | 내 정보 · 회원 탈퇴 | `app/(main)/me` |
| `/share/{token}` | 확정 일정 공개 페이지 | `app/share/[token]` |

> `(main)` 아래 화면은 `app/(main)/layout.tsx` 가 로그인·온보딩 완료 여부를 확인한 뒤에만 보여 줍니다.

## 4. 공통 컴포넌트

| 컴포넌트 | 위치 | 용도 |
| --- | --- | --- |
| `AppFrame` | `components/layout` | 로그인 후 화면의 위쪽 메뉴 + 본문 틀 (모바일에서는 메뉴가 접힘) |
| `AuthFrame` | `components/layout` | 로그인 · 회원가입 카드 틀 |
| `PageLoading`, `ErrorNote` | `components/layout/PageState.tsx` | 불러오는 중 표시, 요청 실패 안내 |
| `useConfirm` | `components/layout` | 확인 대화상자. 브라우저 기본 `confirm` 대신 사용 |
| `TimetableGrid` | `components/timetable` | 주간 시간표 격자. `onPaint` 를 넘기면 누르거나 끌어서 칠할 수 있음 |
| `TimetableEditor` | `components/timetable` | 칠하기 도구 + 한 주 요약 + 저장 |
| `CandidateList` | `components/meeting` | 추천 시간 카드 · 투표 · 마감 · 확정 |
| `WeekMap` | `components/meeting` | 추천 시간이 한 주의 어디에 있는지 보여 주는 지도 |

확인 대화상자는 아래처럼 씁니다.

```tsx
const [confirm, dialog] = useConfirm();

const ok = await confirm({
  title: "이 메모를 삭제할까요?",
  description: "삭제한 메모는 되돌릴 수 없어요.",
  actionLabel: "삭제",
  tone: "destructive",
});
if (!ok) return;

// 화면 어딘가에 {dialog} 를 한 번 넣어 둡니다.
```

## 5. 디자인 시스템 (Astryx)

- 버튼·입력창·카드·탭·대화상자 등은 **직접 만들지 말고 Astryx 컴포넌트**를 씁니다.
- 색·간격·모서리는 **테마 토큰**(`--color-accent` 등)을 쓰고, 색상 코드(#hex)를 화면 코드에 직접 적지 않습니다.
- 컴포넌트 사용법은 CLI 로 확인합니다.

```bash
npx astryx component --list        # 컴포넌트 목록
npx astryx component Button        # 특정 컴포넌트 사용법 (props · 예시)
npx astryx search "파일 업로드"     # 필요한 것을 검색
```

### 테마 수정

테마는 `themes/teum/` 이 원본이고, `src/themes/teum/` 과 `src/astryx-themes.ts` 는 편집기가 만드는 사본입니다. **사본은 직접 고치지 않습니다.**

```bash
npx astryx experimental theme editor show teum                 # 현재 설정 확인
npx astryx experimental theme editor set teum accent "#036635"  # 강조색 변경 예시
npx astryx experimental theme editor how "버튼 모서리를 더 둥글게"  # 방법 물어보기
```

### globals.css 주의사항

`globals.css` 맨 위의 `@layer` 줄이 스타일 우선순위를 정합니다. 이 줄은 **`@import "tailwindcss"` 보다 위**에 있어야 하고, `layout.tsx` 에서 `globals.css` 를 **가장 먼저** 불러와야 합니다. 순서가 바뀌면 오류 없이 화면만 깨집니다.

## 6. 백엔드 연결

- 모든 호출은 `src/lib/api.ts` 의 `authFetch` (로그인 필요) / `apiFetch` (공개) 를 거칩니다. 실패는 `ApiError` 로 통일됩니다.
- 기능별 함수는 `src/lib` 아래 파일로 나뉩니다.

| 파일 | 담당 |
| --- | --- |
| `auth-flow.ts` | 로그인 후 이동 경로 판단, Google 로그인 시작 · 복귀 처리 |
| `timetable-api.ts`, `timetable.ts` | 시간표 조회 · 저장 · 이미지 인식, 비트열 변환 |
| `meetings.ts` | 모임 생성 · 수정 · 삭제, 팀원 추가, 관리자 위임, 나가기 |
| `candidates.ts` | 추천 시간 조회 |
| `votes.ts` | 투표 · 집계 · 마감 |
| `confirm.ts` | 일정 확정, 공유 링크 발급, 공개 일정 조회 |
| `memos.ts` | 모임 메모 |

- 시간표는 **7일 × 26칸(09:00~22:00, 30분 단위) = 182비트** 문자열 두 개(`class_bits`, `manual_bits`)로 주고받습니다. `1` = 비어 있음, `0` = 일정 있음.

## 7. 자주 겪는 문제

- **화면이 '불러오는 중'에서 멈춤** → 주소창이 `http://localhost:3000` 인지 확인. 터미널의 `Network:` 주소(예: `172.x.x.x:3000`)로 열면 개발 서버가 연결을 막아 화면이 멈춥니다.
- **저장·조회가 "…하지 못했어요"로 실패** → 백엔드(`http://localhost:8000/docs`)가 켜져 있는지, 주소가 `localhost:3000` 인지 확인. 백엔드 CORS 가 `http://localhost:3000` 만 허용합니다.
- **`Module not found` (astryx · heroicons 등)** → 브랜치를 받은 뒤 `npm install` 을 다시 실행.
- **예전 디자인이 섞여 보임** → `.next` 폴더를 지우고 `npm run dev` 재실행 후 강력 새로고침(Ctrl+Shift+R).
- **`npm run build` 가 보안 안내를 띄우고 멈춤** → Next.js 16.4.2 의 보안 권고 때문입니다. 한 번 더 실행하면 진행되며, 16.4.6 으로 올리면 사라집니다 (teum-frontend PR #28).
