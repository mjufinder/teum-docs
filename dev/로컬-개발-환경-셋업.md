# 로컬 개발 환경 셋업

백엔드(FastAPI) + 프론트(Next.js) + DB/인증(Supabase)을 **각자 컴퓨터에서 로컬로** 돌리는 방법입니다.

> **현재 상태 (2026-10-31 기준)**
> - DB/인증은 **Supabase CLI + Docker**로 로컬에서 동작합니다. (공유 원격 DB 아님 — 각자 로컬에 동일한 DB를 띄웁니다)
> - **기본 이메일 로그인** 구현 완료 (회원가입/로그인/온보딩/탈퇴 + 프론트 페이지 연동·테스트 완료).
> - **구글 소셜 로그인은 보류** 상태입니다. (Google Cloud 자격증명 확보 후 설정 토글 + 프론트 버튼만 추가하면 되며, 백엔드 코드 변경은 없습니다.)
> - 작업은 **`dev` 브랜치 기준으로 브랜치를 파서** 진행합니다. (백엔드/프론트 레포 모두 `dev` 존재)

---

## 1. 사전 준비 (최초 1회)

- **Docker Desktop** 설치 후 실행 (로컬 Supabase 컨테이너 구동용)
- **Supabase CLI**
  ```bash
  brew install supabase/tap/supabase      # macOS
  # Windows: scoop install supabase  /  문서: https://supabase.com/docs/guides/cli
  ```
- **Python 3.11+**, **Node.js 20+**

---

## 2. 작업 브랜치 생성 (dev 기준)

```bash
git checkout dev && git pull
git checkout -b feat/본인작업      # 예: feat/ocr
```

---

## 3. 백엔드 (teum-backend)

```bash
cd teum-backend

# 로컬 Supabase 기동 — DB 스키마(migrations)가 자동 적용됩니다 (Docker 필요)
supabase start

# 파이썬 가상환경 + 의존성
python3 -m venv .venv
source .venv/bin/activate              # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# 환경변수 (.env.example 의 로컬 표준값을 그대로 쓰면 됩니다)
cp .env.example .env

# 개발 서버 실행
uvicorn app.main:app --reload
```

- API: http://localhost:8000
- Swagger 문서: http://localhost:8000/docs

---

## 4. 프론트엔드 (teum-frontend)

```bash
cd teum-frontend
npm install
cp .env.example .env.local             # 로컬 표준값 그대로 OK
npm run dev
```

- 앱: http://localhost:3000
- 로그인 체험: `/login`, 회원가입: `/signup`, 내 정보/온보딩: `/me`

---

## 5. 로컬 Supabase 운영

| 작업 | 명령 / 주소 |
| --- | --- |
| 기동 | `supabase start` |
| 중지 (데이터 유지) | `supabase stop` |
| 접속 정보 확인 | `supabase status` |
| 테이블 확인 (웹 UI) | Supabase Studio → http://127.0.0.1:54323 |
| 메일 확인 (로컬) | Mailpit → http://127.0.0.1:54324 |

> `.env` / `.env.local` 에 넣는 URL·키는 **로컬 CLI 표준값**이라 팀원 전원 동일합니다.
> (로컬 전용 데모 키 — 비밀값 아님) `.env.example` 에 들어있는 값을 그대로 복사하면 됩니다.

## 7. 자주 겪는 문제

- **`supabase start` 실패 / Auth 페이지 로드 안 됨** → Docker Desktop이 실행 중인지 확인. (데몬이 꺼지면 컨테이너가 전부 내려갑니다.)
- **`StatusDbNotReadyError`** → DB 컨테이너 기동 중. 잠시 후 `supabase start` 재시도.
- **`uvicorn` 실행 시 `cannot execute` 오류** → venv 경로 문제일 수 있습니다. `python -m uvicorn app.main:app --reload` 로 실행.
- **백엔드가 `SUPABASE_URL ... 설정되지 않았습니다`** → `.env` 를 만들었는지 확인 (`cp .env.example .env`).
